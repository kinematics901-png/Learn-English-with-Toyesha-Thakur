About this website

This learning website is built for English grammar teaching and practice. Its study structure follows the attached English Grammar & Writing Self-Study Master Book: 20 chapters, topic-wise theory, examples and a 50,000-question practice structure.

Teacher character: the provided character image is used as a static teacher guide. There is intentionally no eye-blinking animation.
Offline-first: grammar content, tests, progress and admin edits work locally in the browser. No external API is required for core functionality.
Admin demo: frontend-only authentication is not production-grade security. Use the Admin Panel to edit content on this device.
